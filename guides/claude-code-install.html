Claude Code 설치 가이드 (Windows / Mac) ​

Claude Code는 터미널에서 사용하는 Anthropic의 공식 CLI 도구다. 이 책의 실습에서는 npm으로 설치한다.

  • 공식 문서: https://code.claude.com/docs/en/setup

사전 준비: Claude Code를 npm으로 설치하려면 Node.js 18 이상이 필요하다. Windows에서는 Git for Windows(Git Bash)를 함께 설치하면 Claude Code가 Bash 도구를 사용할 수 있다.

1. 시스템 요구 사항 ​

항목요구 사항
운영체제macOS 13.0+ / Windows 10 1809+ / Ubuntu 20.04+ / Debian 10+ / Alpine 3.19+
하드웨어RAM 4GB 이상, x64 또는 ARM64 프로세서
네트워크인터넷 연결 필요
셸Bash, Zsh, PowerShell, CMD
계정Pro, Max, Team, Enterprise 또는 Console 계정 (무료 Claude.ai 플랜은 미포함)

2. 설치하기 ​

방법 A. npm으로 설치 (이 책의 기준) ​

Node.js가 설치되어 있으면 어느 OS에서든 동일한 명령으로 설치할 수 있다. Windows는 Git Bash 터미널에서, Mac은 기본 터미널에서 실행한다.

bash
npm install -g @anthropic-ai/claude-code

명령어 풀이:

  • npm은 Node.js 기반 프로그램을 설치하는 도구다.
  • install -g는 어느 폴더에서든 claude 명령을 사용할 수 있게 전역 설치한다는 뜻이다.
  • @anthropic-ai/claude-code는 설치할 Claude Code 패키지 이름이다.

⚠️ sudo npm install -g는 사용하지 않는다. 권한 문제와 보안 위험이 생길 수 있다.

업그레이드는 npm install -g @anthropic-ai/claude-code@latest로 한다. (npm update -g는 최신 버전으로 올라가지 않을 수 있다.)

방법 B. 네이티브 설치 (공식 권장) ​

npm 없이 설치 스크립트로 바로 설치할 수도 있다. 네이티브 설치본은 백그라운드에서 자동 업데이트된다.

macOS / Linux / WSL:

bash
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell:

powershell
irm https://claude.ai/install.ps1 | iex

Windows CMD:

batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

방법 C. 패키지 관리자로 설치 ​

  • macOS (Homebrew):

    bash
    brew install --cask claude-code

  • Windows (WinGet):

    powershell
    winget install Anthropic.ClaudeCode

Homebrew·WinGet 설치본은 자동 업데이트되지 않는다. brew upgrade claude-code 또는 winget upgrade Anthropic.ClaudeCode로 수동 업데이트한다.

3. Windows에서의 추가 안내 ​

Windows에서는 네이티브 Windows 또는 WSL 중 선택해 실행할 수 있다.

  • Git for Windows(Git Bash) 설치 시: Claude Code가 Git Bash를 Bash 도구로 사용한다. (권장)
  • Git for Windows 미설치 시: Claude Code가 PowerShell을 셸 도구로 사용한다.

Claude Code가 Git Bash 경로를 찾지 못하면 settings.json에 경로를 지정한다.

json
{
  "env": {
    "CLAUDE_CODE_GIT_BASH_PATH": "C:\\Program Files\\Git\\bin\\bash.exe"
  }
}

4. 설치 확인 ​

설치가 끝나면 아래 명령으로 정상 설치 여부를 확인한다.

bash
claude --version

더 자세한 진단이 필요하면 다음을 실행한다.

bash
claude doctor

command not found 같은 오류가 나면 터미널을 닫았다가 다시 열고 재시도한다.

5. 첫 실행 및 로그인 ​

작업할 프로젝트 폴더로 이동한 뒤 아래 명령으로 Claude Code를 시작한다.

bash
claude

처음 실행하면 브라우저가 열리며 로그인 절차가 진행된다. 화면 안내에 따라 로그인하면 된다.

Claude Code는 Pro, Max, Team, Enterprise 또는 Console 계정이 필요하다. Amazon Bedrock, Google Vertex AI, Microsoft Foundry 같은 외부 API 제공자와도 연동할 수 있다.

6. 업데이트 ​

  • 네이티브 설치본: 백그라운드 자동 업데이트
  • npm 설치본: npm install -g @anthropic-ai/claude-code@latest
  • 즉시 업데이트: claude update

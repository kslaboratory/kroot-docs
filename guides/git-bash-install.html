Git Bash 설치 가이드 (Windows) ​

Git Bash는 Windows에서 git, ls, cd, mkdir 같은 명령을 편하게 사용할 수 있게 해 주는 터미널 환경이다. 이 책의 실습은 Windows에서 Git Bash 기준으로 진행한다.

Mac 사용자는 Git이 기본 제공되거나 처음 실행 시 개발자 도구 설치 안내가 나오므로, 이 문서를 따로 따라 할 필요가 없다. 터미널에서 git --version으로 확인만 하면 된다.

  • 공식 다운로드: https://git-scm.com
  • 본 가이드 출처(설치 화면): https://xangmin.tistory.com/102

1. 설치 파일 다운로드 ​

Git 공식 홈페이지(https://git-scm.com)에 접속해 Windows용 설치 파일을 내려받는다.

2. 라이선스 정보 확인 ​

설치 파일을 실행하면 Git Bash의 정보와 라이선스(GNU General Public License) 내용이 표시된다. Next를 누른다.

3. 설치 경로 지정 ​

Git을 설치할 폴더를 선택한다. 특별한 이유가 없으면 기본 경로(C:\Program Files\Git)를 그대로 두고 Next를 누른다.

4. 컴포넌트 선택 ​

설치할 구성 요소를 선택한다. 기본값으로 두고 Next를 눌러도 충분하다. (Git Bash Here, Git GUI Here 등이 기본 선택되어 있다.)

5. 시작 메뉴 폴더 선택 ​

시작 메뉴에 폴더를 추가하고 싶지 않으면 Don't create a Start Menu folder 체크박스를 선택한다. 보통은 기본값으로 두고 Next를 누른다.

6. 기본 에디터 설정 ​

Git이 사용할 기본 텍스트 에디터를 선택한다. VS Code처럼 평소 사용하는 에디터가 있다면 해당 에디터로 설정한다. 잘 모르겠으면 기본값(Vim)으로 두고 Next를 눌러도 된다.

7. 초기 브랜치 이름 설정 ​

새 저장소를 만들 때 사용할 초기 브랜치 이름을 정한다. 기본값(Let Git decide)으로 두고 Next를 누르면 된다.

8. PATH 환경 설정 ​

명령행에서 Git을 어떻게 사용할지 선택한다. 권장 옵션인 Git from the command line and also from 3rd-party software가 기본 선택되어 있다. 그대로 두고 Next를 누른다.

9. HTTPS 전송 방식 선택 ​

HTTPS 연결에 사용할 라이브러리를 선택한다.

  • Use the OpenSSL library: OpenSSL 라이브러리를 사용하고 ca-bundle.crt 파일로 인증서 유효성을 검사한다. (기본값)
  • Use the native Windows Secure Channel library: Windows 인증서 저장소를 사용해 인증서 유효성을 검사한다.

기본값으로 두고 Next를 누른다.

10. 줄 끝(Line Ending) 변환 방식 ​

텍스트 파일의 줄 끝 문자를 어떻게 변환할지 선택한다. 기본값으로 두어도 무관하다.

11. 터미널 에뮬레이터 선택 ​

Git Bash에서 사용할 터미널 에뮬레이터를 선택한다. 기본값(Use MinTTY)으로 두어도 무관하다.

12. git pull 기본 동작 선택 ​

git pull 실행 시 기본 동작을 선택한다. 기본값(Default (fast-forward or merge))으로 두고 Next를 누른다.

13. 자격 증명 관리자(Credential Helper) ​

자격 증명 저장 방식을 선택한다. 기본값(Git Credential Manager Core)으로 두고 Next를 누른다.

14. 추가 옵션 ​

추가 옵션을 선택한다.

  • Enable file system caching: 성능 향상을 위해 파일 시스템 데이터를 메모리에 캐시한다. (기본 선택)
  • Enable symbolic links: 심볼릭 링크를 활성화한다. (기존 저장소는 영향을 받지 않음)

기본값으로 두고 Next를 누른다.

15. 실험적 옵션 ​

실험적 기능 옵션이다. 그대로 두고 Install을 눌러 설치를 시작한다.

16. 설치 진행 ​

설치가 진행된다. 잠시 기다린다.

17. 설치 완료 ​

설치가 끝나면 완료 화면이 나타난다. Finish를 눌러 마법사를 종료한다.

18. 설치 확인 ​

시작 메뉴에서 Git Bash가 보이면 정상이다. Git Bash 터미널을 열고 아래 명령을 실행해 버전이 출력되는지 확인한다.

bash
git --version

버전 번호가 보이면 Git Bash 설치가 완료된 것이다.

Antigravity IDE를 사용한다면, 내장 터미널의 + 또는 아래 화살표 메뉴에서 Git Bash를 선택해 터미널을 Git Bash로 바꿔서 사용한다.

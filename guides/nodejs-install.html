Node.js 설치 가이드 (Windows / Mac) ​

Node.js를 설치하면 함께 제공되는 npm을 사용할 수 있다. 이 책에서는 Claude Code를 npm으로 설치하므로 Node.js가 반드시 필요하다.

처음 설치하는 사람은 LTS(장기 지원) 버전을 선택하면 된다.

  • 공식 다운로드: https://nodejs.org/ko
  • 본 가이드 출처(설치 화면): https://happy-metamong.tistory.com/26

A. Windows에 설치하기 ​

A-1. 설치 파일 다운로드 ​

Node.js 공식 다운로드 페이지에 접속해 LTS 버전을 선택한다.

A-2. 시스템 종류 확인 (선택) ​

내 컴퓨터가 64비트인지 확인하려면 시스템 > 정보에서 시스템 종류를 확인한다. 대부분의 최신 PC는 64비트(x64)다.

A-3. 내려받은 설치 파일 실행 ​

다운로드 폴더에서 node-vXX.X.X-x64.msi 설치 파일을 실행한다.

A-4. 설치 마법사 시작 ​

Welcome to the Node.js Setup Wizard 화면에서 Next를 누른다.

A-5. 라이선스 동의 ​

I accept the terms in the License Agreement 체크박스를 선택하고 Next를 누른다.

A-6. 설치 경로 설정 ​

기본 경로(C:\Program Files\nodejs\)를 유지하고 Next를 누른다.

A-7. Custom Setup ​

Node.js runtime, npm package manager, Add to PATH가 선택되어 있는지 확인하고 Next를 누른다.

A-8. Tools for Native Modules (선택) ​

추가 개발 도구(Python, Visual Studio Build Tools) 설치 옵션이다. 단순히 Claude Code만 사용할 목적이라면 체크하지 않아도 된다. 그대로 Next를 누른다.

A-9. 설치 시작 ​

Install 버튼을 눌러 설치를 시작한다.

A-10. 설치 진행 ​

설치가 진행된다. 잠시 기다린다.

A-11. 설치 완료 ​

Finish를 눌러 설치를 종료한다.

A-8에서 추가 개발 도구를 체크했다면, 설치 종료 후 검은색 명령창이 자동으로 열려 Python과 Visual Studio Build Tools를 추가로 설치한다. 안내에 따라 진행하면 된다.

A-12. 설치 확인 ​

명령 프롬프트(또는 Git Bash)를 열고 아래 명령으로 버전을 확인한다.

bash
node -v
npm -v

버전 번호가 보이면 Windows 설치가 완료된 것이다.

B. Mac에 설치하기 (pkg 설치 프로그램) ​

B-1. 설치 파일 다운로드 ​

Node.js 공식 페이지에서 macOS용 설치 프로그램(.pkg)을 내려받는다.

B-2. 내려받은 pkg 파일 실행 ​

다운로드 폴더에서 node-vXX.X.X.pkg 파일을 실행한다.

B-3. 소개 화면 ​

설치 프로그램이 node와 npm을 /usr/local/bin에 설치한다고 안내한다. 계속을 누른다.

B-4. 사용권 계약 동의 ​

라이선스 동의 화면에서 계속 → 동의를 누른다.

B-5. 설치 유형 선택 ​

Macintosh HD에 표준 설치를 선택하고 설치를 누른다. Mac 비밀번호를 입력하라는 화면이 나오면 입력한다. (입력 시 화면에 글자가 보이지 않아도 정상이다.)

B-6. 설치 완료 ​

설치가 성공적으로 완료되었습니다 메시지가 나오면 닫기를 누른다.

B-7. 설치 확인 ​

터미널을 열고 아래 명령으로 버전을 확인한다.

bash
node -v
npm -v

버전 번호가 보이면 정상이다.

C. Mac에 설치하기 (Homebrew) ​

이미 Homebrew를 사용하고 있다면, 터미널에서 한 줄로 설치할 수 있다.

C-1. Homebrew로 설치 ​

bash
brew install node

C-2. 설치 확인 ​

bash
node -v
npm -v

버전 번호가 보이면 정상이다.

설치가 끝난 뒤에는 Antigravity IDE를 닫았다가 다시 여는 편이 안전하다. 새로 설치된 node/npm 명령을 IDE 터미널이 다시 읽어야 하기 때문이다.

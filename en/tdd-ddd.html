TDD and DDD ​

KRoot-ADK keeps behavior-preserving development as a working principle through the current command, skill, and pipeline agents.

Current Entry Points ​

NeedUse
General refactoring/kroot:refactor
Test generation or execution/kroot:test
Full verification/kroot:verify
Pipeline implementation stageskroot-s09-frontend, kroot-s10-backend, kroot-s11-testing through kroot-workflow-pipeline

Recommended Cycle ​

  1. Analyze the current behavior.
  2. Preserve important behavior with tests or explicit acceptance checks.
  3. Improve the code in small, reviewable changes.
  4. Run the relevant verification command.

For formal KRoot Pipeline work, the active stage gate still applies before any stage agent runs.
